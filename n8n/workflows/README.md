# n8n Workflows Directory

This directory stores exported n8n workflow definitions for external orchestration:

- `01-product-hunter.json`
- `02-product-analysis.json`
- `03-affiliate.json`
- `04-image-generation.json`
- `05-script-generation.json`
- `06-video-generation.json`
- `07-video-variations.json`
- `08-live-loop.json`
- `09-analytics.json`
- `10-optimization.json`

> **Note**: The core backend handles all critical jobs autonomously. n8n workflows act as an optional orchestration layer interacting via REST APIs and Webhooks.
