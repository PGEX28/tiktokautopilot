# Supabase & PostgreSQL Migrations Directory

This directory holds SQL migrations, RLS policies, table schemas, and seeds for the **TikTok Shop AI Autopilot** database.

In **ETAPA 2**, migrations covering all 25 system tables (`users`, `tiktok_accounts`, `products`, `product_scores`, `video_variations`, `live_loops`, `metrics`, `jobs`, `system_logs`, etc.) will be created here.
